## 基岩版支持范围

| 能力 | 实现 |
| --- | --- |
| 新建实例 | 新建页可选「Java 版 / 基岩版」，基岩版版本取微软官方接口的最新 BDS |
| 核心下载 | 读微软下载清单接口（`serverBedrockLinux`），不再硬编码版本号 |
| 运行环境 | 自动准备 `proot`（Termux 源）+ Ubuntu base rootfs；首次约 30MB，后台线程执行不卡界面 |
| 端口 | 固定 UDP 19132，首次安装时写入 `server.properties` |
| 资源 | CurseForge gameId 78022，五类资源按类别落到 `behavior_packs` / `resource_packs` / `worlds` / `skins` |

## 已知限制（不算缺项，但要知道）

| 项 | 说明 |
| --- | --- |
| 联机「悬浮窗」 | 用应用内底部弹层实现（浮在控制台上方），不是系统级悬浮窗（那需要 `SYSTEM_ALERT_WINDOW` 常驻权限，收益不抵风险） |
| 联机断开 | 官方没有「断开」API，退出只是复位到待机；彻底断开需重启应用 |
| mrpack 导出 | 未记录模组下载直链与哈希，资源走 `overrides/`，包体偏大但内容完整 |
| FPS 上限 | Compose 无法真正锁帧，换算成控制台刷新间隔生效 |
| NBT 编辑器 | 只允许改标量；服务端运行时修改会被覆盖（界面已警告） |
| 基岩版 | 资源只有 CurseForge 数据源（Modrinth 无基岩内容），需自行确认版本匹配 |
| 基岩版运行 | 必须 proot + glibc rootfs（Ubuntu base 24.04，约 30MB，首次自动下载）；rootfs 与 BDS 的 ABI 必须一致（arm64 / amd64） |
| 基岩版版本 | 官方只提供「最新版」直链，无法像 Java 版那样选历史版本 |
